## 2. 配置 request 合法域名 + 上传密钥

### 2.1 request 合法域名

微信公众平台 → 开发管理 → 开发设置 → 服务器域名：

```
request 合法域名：https://templio.wdbzk.com
```

> 只需 request；不需要 uploadFile/downloadFile/socket。
> 开发者工具本地调试已设置 `urlCheck: false`，真机/体验版必须配置。

### 2.2 代码上传密钥

微信公众平台 → 开发管理 → 开发设置 → 小程序代码上传 → 生成/下载密钥：

1. 下载 `private.<appid>.key` 文件
2. 转 base64：

```powershell
# Windows PowerShell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("private.wx5f21980e48e92ae6.key")) | Set-Clipboard
```

3. 仓库 Settings → Secrets and variables → Actions：
   - `WX_APPID` = `wx5f21980e48e92ae6`
   - `WX_PRIVATE_KEY` = 上一步的 base64

### 2.3 上传体验版

**先处理密钥 IP 白名单（必须）：**

微信公众平台 → 开发管理 → 开发设置 → 小程序代码上传 → 代码上传密钥 → 编辑 IP 白名单：

- 添加当前出口 IP：`36.161.20.110`
- 或直接关闭 IP 白名单（仅建议在可信网络）

未配置时会报：

```
{"errCode":-10008,"errMsg":"invalid ip: 36.161.20.110"}
```

本机直接上传：

```powershell
$env:WX_APPID = "wx5f21980e48e92ae6"
$env:WX_PRIVATE_KEY_PATH = "C:\Users\Admin\Downloads\private.wx5f21980e48e92ae6.key"
node scripts/upload-miniprogram.mjs --version 0.1.0 --desc "模板宝 体验版 2026-11-02"
```

上传成功后到公众平台「版本管理 → 开发版本」设为体验版。

GitHub Actions → `Upload miniprogram` → Run workflow：

| 输入 | 示例 |
| --- | --- |
| version | `0.1.0` |
| desc | `模板宝 体验版` |

成功后：微信公众平台 → 版本管理 → 开发版本 → 设为体验版 / 提交审核。

本地也可 dry-run：


## 3. 用户隐私保护指引（可直接粘贴）

> 在微信公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引 中填写。

**收集的信息：**

1. 微信 openid（用户唯一标识）：用于免登录、收藏与下载记录同步。
2. 收藏记录、下载记录、浏览记录：用于在「我的」中展示用户数据。
3. 不收集手机号、位置、通讯录、相册、剪贴板内容。

**使用目的：**

- openid：识别用户身份，提供收藏/下载记录跨设备同步。
- 收藏/下载/浏览记录：展示个人收藏与下载历史，改进模板推荐。
- 设备与日志信息（IP、请求时间）：用于安全防护与故障排查。

**存储与删除：**

- 数据存储在模板宝服务器（中国境内），保存期限为账号使用期间。
- 用户可在小程序内「我的 → 注销账号」直接删除个人数据（收藏/下载/浏览记录）。
- 也可通过「我的 → 意见反馈」或邮箱 `feedback@wdbzk.com` 申请删除。
- 注销后个人数据不可恢复；再次进入小程序会创建新的空白账号。

**第三方共享：**

- 仅使用微信登录接口换取 openid，不向其他第三方共享个人信息。
- 模板下载通过百度网盘/夸克网盘短链完成，用户需遵守对应网盘服务条款。

**联系方式：**

- 邮箱：`feedback@wdbzk.com`

> 请把 `feedback@wdbzk.com` 改成你实际可用的邮箱；如需更严谨，可另建隐私政策页面并在小程序内链接。

## 5. 常见审核问题

| 问题 | 处理 |
| --- | --- |
| request 域名未配置，真机请求失败 | 按 2.1 配置后重新上传体验版 |
| 上传报 `invalid ip` | 按 2.3 把当前出口 IP 加入密钥白名单，或关闭白名单 |
| 隐私指引未填写，审核驳回 | 按第 3 节填写并提交 |
| 涉及「网盘下载」被要求说明 | 说明仅提供用户自行上传的模板文件分享链接，平台不存储源文件 |
| 模板版权投诉 | 提供模板来源/授权说明，或下架对应模板 |
| 体验版无法登录 | 检查服务器 `.env` AppID/Secret、`/api/user/login`、request 域名 |
