# 本地生成封面、缩略图与预览图

> 不想敲命令可以使用桌面工作台：
> 双击 `release\模板宝工作台-win32-x64\模板宝工作台.exe`，
> 或双击仓库根目录的 `启动模板宝工作台.bat`。
> 生成后可直接点「上传到服务器」，无需执行下面的命令。

> 渲染只在 Windows 桌面执行，服务器 2C2G 不跑 LibreOffice。

## 1. 环境

| 依赖 | 要求 |
| --- | --- |
| Node.js | ≥ 22.12 |
| LibreOffice | Windows 安装版，能找到 `soffice.com` |
| 中文字体 | 已安装模板使用的字体，否则渲染会漂移 |

首次：

```powershell
cd D:\Personal\products\templio
npm ci
npm run build
npm run doctor
```

`doctor` 会检查 LibreOffice、中文字体和图片预算。

## 2. 准备源文件

把 `.pptx` / `.docx` 放进一个目录，渲染会递归扫描：

```text
D:\templates\src\
  ├── 商务汇报.pptx
  ├── 教学课件.pptx
  └── 合同模板.docx
```

## 3. 渲染物料包

```powershell
npm run render -- "D:\templates\src" --out "D:\templates\packages" --preview-pages 4 --force
```

参数：

| 参数 | 说明 |
| --- | --- |
| `--out` | 输出目录，默认 `dist-packages` |
| `--preview-pages` | 预览页数量（含封面页），默认 4 |
| `--render-width` | PDF 渲染宽度，默认 1600 |
| `--concurrency` | 并发数，默认 2 |
| `--force` | 忽略渲染记录强制重跑 |

输出结构：

```text
D:\templates\packages\
└── <hash8>-<文件名>\
    ├── images\
    │   ├── cover.webp      # 详情封面 800×450（16:9）
    │   ├── thumb.webp      # 列表缩略图 360×203（16:9）
    │   ├── preview-01.webp # 预览图，宽 800
    │   └── preview-02.webp ...
    ├── source\
    │   └── 原文件.pptx
    ├── manifest.json
    └── text.json
```

图片规格来自 `packages/shared/src/index.ts` 的 `IMAGE_SPEC`：

| 图片 | 尺寸 | 单张预算 |
| --- | --- | --- |
| 封面 | 800×450（16:9） | 120KB |
| 缩略图 | 360×203（16:9） | 30KB |
| 预览图 | 宽 800，等比 | 80KB |

PPT 首屏按 16:9 满幅裁切；竖版 Word 仍使用模糊背景 + 完整页面居中。上传带源文件时，会先清理 Office 文档属性中的原作者、最后修改者、公司、店铺/关键词等元数据，再上传到服务器和网盘。

## 4. 检查物料包

```powershell
npm run status -- "D:\templates\packages"
```

## 5. 上传到服务端

上传会创建「已导入」模板，之后到管理端复核、AI 标注、配置网盘并上架。

```powershell
$env:TEMPLIO_ADMIN_PASSWORD = "管理员密码"
node apps/desktop-cli/dist/index.js upload "D:\templates\packages" --api https://templio.wdbzk.com
```

需要同时暂存源文件（供后续网盘同步，同步成功后服务器删除）：

```powershell
node apps/desktop-cli/dist/index.js upload "D:\templates\packages" --with-source --api https://templio.wdbzk.com
```

## 6. 注意事项

- 同一批物料包重复执行 `render` 会跳过已渲染项，改代码或源文件后用 `--force`。
- 上传按 `sourceHash` 去重；修改已有模板封面时，需要先在管理端删除旧模板，再重新上传同一物料包。
- 封面采用「模糊背景 + 页面居中」的 3:4 构图；DOCX 白底页面左右会有灰色衬底，小程序端已做裁边显示。
- 物料包里的 `source/` 优先硬链接；源文件与输出在同一磁盘时不额外占用源文件体积，跨盘时自动复制。
- 如果只想要图片文件，不执行第 5 步即可，图片就在 `images/` 目录。
