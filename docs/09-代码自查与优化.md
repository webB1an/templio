## 2. 已修复的问题

| 等级 | 问题 | 修复 |
| --- | --- | --- |
| 高 | 收藏计数存在并发/历史漂移，极端情况下被减成负数 | 取消收藏改为按 `deleteMany` 实际删除行数减计数；新增 `scripts/reconcile-favorites.mjs` 按真实收藏行重算 |
| 中 | 并发收藏时唯一键冲突会报 500 | 捕获 Prisma `P2002`，按已收藏处理 |
| 中 | 管理端导入先写图片后校验源文件，校验失败会留下孤儿图片 | 先校验源文件；写入/建库失败时清理本次已落盘文件 |
| 中 | 同一模板可同时发起多个网盘同步任务，会互相踩踏源文件和链接 | 增加同模板 queued/running 任务检查；超过 30 分钟的任务自动标记超时 |
| 中 | 网盘上传成功后源文件清理失败会把整个任务标记为失败 | 清理失败只记录 warning，同步结果保持成功 |
| 中 | 登录限流读取 `X-Forwarded-For` 首项，可被客户端伪造绕过 | 改读 Nginx 覆盖写入的 `X-Real-IP`；Nginx 示例改为覆盖 XFF |
| 中 | CLI 可把预览页数设为 >8，导致 manifest 校验失败 | CLI 统一限制 1–8 页 |
| 中 | CLI 允许输出目录放在源目录内，下次扫描会扫到生成包里的 source | CLI 与桌面工作台都阻止该配置 |
| 中 | `INCOMING_QUOTA_GB` 只有参数、没有实际校验，批量上传源文件可写满 40GB 磁盘 | 导入时汇总当前源文件占用，超过配额返回 503 |
| 中 | 物料包复制源文件会额外占用几十 GB 本地空间 | 同磁盘优先硬链接，跨盘回退复制 |
| 低 | 小程序并发 401 会重复触发 `wx.login`；详情页空 id 会触发无意义登录 | 复用进行中的登录 Promise；空 id 直接跳过收藏状态查询 |
| 低 | 详情页主视觉预览图损坏时可能空白 | 预览图加载失败时退回封面图 |
| 低 | CSV 导出字段以 `= + - @` 开头时可能被 Excel 当作公式 | 导出时加前导 `'` |
| 低 | 管理端网盘同步提示仍写 `NETDISK_SYNC_COMMAND` | 改为提示使用「网盘账号」默认账号 |

## 4. 待优化项（不阻断当前使用）

1. **自动化测试不足**：目前只有构建、小程序静态检查、`verify:prod` 冒烟验收，没有单元/集成测试。
2. **点击记录无限增长**：`TemplateClick` 没有归档/清理策略，长期运行需要按天聚合或定期清理。
3. **任务队列依赖进程内执行**：PM2 重启时正在运行的同步任务会中断；当前依靠 30 分钟超时兜底，可后续引入持久化队列。
4. **管理端包体较大**：首个 JS chunk 约 1.06MB（gzip 337KB），可对页面做 `React.lazy` 拆包。
5. **导入并发哈希竞争**：同一 `sourceHash` 并发导入时，后失败的一方清理文件可能影响先成功的一方；当前 CLI 串行上传，风险低。
6. **封面灰边来自生成器**：桌面 CLI 的 3:4 封面设计为「模糊底 + 居中页面」，已有前端裁边兜底；后续可改为全幅裁切生成。
7. **私网备份范围**：备份脚本备份数据库与 `storage/public`，源文件暂存区不备份（源文件设计为同步后删除），需在运营文档明确。
8. **生产 Nginx 的实际配置**仍使用 `$proxy_add_x_forwarded_for`；应用已改用 `X-Real-IP`，建议后续同步示例配置。

## 5. 结论

未发现阻断上线的逻辑性问题。核心链路的已知问题已修复；剩余主要是测试、长期数据清理、包体与队列健壮性优化。
