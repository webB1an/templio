> 版本：v0.1（P0 可运营）
> 线上地址：<https://templio.wdbzk.com>　管理端：<https://templio.wdbzk.com/admin/>
> 服务器：2 核 / 1.67G / 40G（Alibaba Cloud Linux 4）

## 1. 系统组成

| 模块 | 路径 | 说明 |
| --- | --- | --- |
| 微信小程序（用户端） | `apps/miniprogram` | 原生 JS + 液态玻璃 UI；静默登录、搜索/分类/详情、收藏、下载记录 |
| Web 管理端 | `apps/admin` | React 19 + Vite + AntD；登录、数据看板、模板库、导入说明 |
| 服务端 | `apps/api` | NestJS 11 + Prisma + MySQL；公开 API / 管理 API / 用户 API |
| 桌面 CLI | `apps/desktop-cli` | LibreOffice 渲染 → 标准物料包 → 上传 |
| 共享契约 | `packages/shared` | 枚举、物料包 schema、图片规格（ESM + CJS 双构建） |
| 部署与运维 | `deploy/`、`.github/workflows/` | Nginx/PM2/备份/健康检查/CI/CD |

线上进程：`pm2` 进程 `templio-api`；Nginx 反代 `/api/`、`/r/`、`/assets/`、`/admin/`。

## 3. 日常运营流程

### 3.1 批量导入模板

```powershell
# 1. 渲染（Windows 桌面，需 LibreOffice + 中文字体）
templio render D:\templates -o D:\templates-dist

# 2. 上传（可带源文件，便于网盘同步）
set TEMPLIO_ADMIN_PASSWORD=<服务器 .env 的 ADMIN_PASSWORD>
templio upload D:\templates-dist --api https://templio.wdbzk.com --with-source
```

- 物料包按源文件 SHA-256 幂等，重复上传返回 `duplicate`
- 导入后状态为 `imported`，公开接口不可见

### 3.2 AI 标注与复核

1. 管理端 → 模板库 → 「AI 批量标注」（一次最多 5 个）
2. 「AI 自动应用」：置信度 ≥90% 且安全的结果批量写回标题/分类/标签/简介
3. 「待复核」筛选，人工检查后上架

### 3.3 网盘与源文件

**先在管理端「网盘账号」在线绑定账号并设默认：**

| 网盘 | 绑定方式 |
| --- | --- |
| 百度 | 浏览器登录 `pan.baidu.com` → 复制请求头 Cookie（需包含 `BAIDUID`、`BDUSS`、`STOKEN`）→ 粘贴到授权弹窗 |
| 夸克 | 新增账号后点「授权」→ 打开授权链接登录 → 粘贴授权码 |

- 每种网盘第一个账号自动设为默认；可手动切换默认账号
- 支持探活、改名、删除；删除有链接的账号会停用并清理授权文件
- 上传同步默认使用「夸克默认 → 百度默认」

| 方式 | 操作 |
| --- | --- |
| 自动同步（推荐） | 模板「网盘」弹窗 → 「同步到网盘」→ 自动上传、分享、生成短链并删除服务器源文件 |
| 手动 | 网盘弹窗 → 下载源文件 → 上传百度/夸克 → 填链接/提取码 → 删除服务器源文件 |

> 夸克自动同步依赖服务器安装 quarkclouddrive Skill，并配置 `QUARK_SKILL_DIR`。
> 百度依赖 `bdpan`（Cookie 认证），配置 `BDPAN_PATH`。

### 3.4 上架/下架

管理端模板库：单条「上架 / 下架」，或勾选后「批量上架 / 批量下架」。
只有 `published` 状态会出现在公开接口与小程序。

### 3.5 数据导出

管理端模板库工具栏：

| 按钮 | 导出内容 |
| --- | --- |
| 导出模板 CSV | 标题/状态/分类/标签/浏览/下载/收藏/短链/提取码/源文件/时间 |
| 导出点击 CSV | 最近 30 天 浏览/复制明细（模板、时间、用户） |

- CSV 带 UTF-8 BOM，Excel 直接打开不乱码
- 点击明细最多 5000 行；需要更长周期时调整 `days` 参数

## 4. 部署

### 4.1 自动部署（推荐）

push 到 `main` → GitHub Actions：

1. CI：commitlint + typecheck/build + LibreOffice 渲染冒烟
2. Deploy：CI 侧构建 → rsync 产物与 `node_modules` 到服务器 → 服务器 `prisma generate/migrate` → PM2 reload → `/health`

**服务器上永远不要执行 `npm install` / `npm run build`**（2C2G 会被拖死）。

### 4.2 回滚

```bash
git revert <bad-commit> && git push origin main
```

或手动 SSH 把数据库/代码切回上一版（当前为 rsync 覆盖式发布）。

### 4.3 常用命令

```bash
ssh templio-server
pm2 status
pm2 logs templio-api --lines 100
pm2 restart templio-api
nginx -t && nginx -s reload
curl -s http://127.0.0.1:4000/health
```

## 5. 备份 / 监控 / 日志

### 5.1 备份（已安装 cron）

| 项 | 说明 |
| --- | --- |
| 时间 | 每天 03:00 |
| 数据库 | `/www/wwwroot/templio/backups/mysql/templio-*.sql.gz`，保留 14 天 |
| 图片 | `/www/wwwroot/templio/backups/storage/storage-*.tar.gz`，保留 7 天 |
| 脚本 | `deploy/server/backup.sh` |
| 日志 | `logs/backup-cron.log` |

手动执行：

```bash
bash /www/wwwroot/templio/deploy/server/backup.sh
```

恢复数据库（会覆盖当前库，先停 PM2 / 做好快照）：

```bash
ssh templio-server
cd /www/wwwroot/templio
pm2 stop templio-api
gunzip -c backups/mysql/templio-YYYYMMDD-HHMMSS.sql.gz | \
  MYSQL_PWD=<密码> mysql -h127.0.0.1 -u<用户> templio
pm2 start templio-api
```

恢复图片：

```bash
tar -xzf backups/storage/storage-YYYYMMDD-HHMMSS.tar.gz -C storage
```

### 5.2 健康检查（已安装 cron）

| 项 | 说明 |
| --- | --- |
| 频率 | 每 5 分钟 |
| 内容 | API `/health`（含 version/commit）、PM2 进程、磁盘 ≥85%、可用内存 <80MB、数据库备份是否超过 24h |
| 脚本 | `deploy/server/healthcheck.sh` |
| 日志 | `logs/healthcheck.log`、`logs/alert.log` |
| 告警 | 可选 `ALERT_WEBHOOK_URL`（企业微信/飞书 text webhook） |

### 5.3 日志轮转

- 配置：`/etc/logrotate.d/templio`（由 `deploy/server/install-ops.sh` 安装）
- 范围：`/www/wwwroot/templio/logs/*.log`
- 策略：daily / 保留 14 天 / gzip / copytruncate

### 5.4 存储清理

清理数据库中已不存在的孤儿图片/源文件目录（默认 dry-run）：

```bash
cd /www/wwwroot/templio/apps/api
set -a; . ./.env; set +a
node ../../scripts/cleanup-storage.mjs            # 仅列出
node ../../scripts/cleanup-storage.mjs --delete   # 确认后删除
```

建议每次删除模板/手工清理后执行一次；不要在备份前删除未知目录。

### 5.5 重新安装运维项

```bash
APP_ROOT=/www/wwwroot/templio bash /www/wwwroot/templio/deploy/server/install-ops.sh
```

## 7. 数据与安全

- 数据库仅监听 `127.0.0.1:3306`，不对公网开放
- 服务器 `.env` 600 权限；仓库无明文密钥
- 管理端 JWT 12 小时；小程序用户 token 30 天，401 自动重登
- 短链 `/r/:code` 只做 302 跳转，不暴露源文件
- 源文件暂存于 `storage/private`，同步网盘后应删除（自动/手动）
- 上传限制：单文件 ≤80MB，Nginx `client_max_body_size 108m`
- 安全响应头：HSTS / `X-Content-Type-Options` / `X-Frame-Options` / `Referrer-Policy` / `Permissions-Policy`
- 隐藏 `X-Powered-By`；CORS 仅允许 `APP_ORIGIN`（可用 `CORS_ORIGINS` 覆盖）
- 登录接口 IP 限流 10 次/分钟（超出 429）

## 9. 故障排查

| 现象 | 排查 |
| --- | --- |
| 域名 502 | `pm2 status`、`pm2 logs templio-api`，确认 API 在线 |
| 管理端登录失败 | 读 `.env` 的 `ADMIN_PASSWORD`；清 localStorage 的 `templio_admin_token` |
| 小程序请求失败 | 检查 request 合法域名、HTTPS、`/api/health` |
| 微信登录失败 | 看 API 日志；确认 `.env` AppID/Secret；fake code 应返回 40029 |
| 图片 404 | 检查 `storage/public/templates/<hash8>/` 与 Nginx `/assets/` alias |
| 导入 500 | 看 `pm2 logs`；常见为磁盘/文件路径问题 |
| 网盘同步失败 | 检查 `NETDISK_SYNC_COMMAND` 是否配置、命令输出 JSON；查看任务 error |
| 备份失败 | `logs/backup-cron.log`，检查磁盘空间与 `mysqldump` 权限 |
